Why AI Should Review Infrastructure Before It Changes Infrastructure

John Terrill · LinkedIn · /writing/ai-should-review-infrastructure

The highest ROI for AI in infrastructure may come before execution.

AI should review infrastructure before it changes infrastructure.

Execution Is Not the First Bottleneck

Generating commands, Terraform, scripts, or policies is increasingly easy.

The harder question is whether the proposed change is safe, necessary, reversible, and well understood.

AI as Reviewer

Before execution, AI can help identify:

  • blast radius
  • hidden dependencies
  • similar prior changes
  • relevant incidents
  • missing assumptions
  • alternative approaches
  • rollback strategy
  • validation steps

Better Human Review

AI should not replace human accountability. It should improve the material humans review.

A human approving a well-analyzed change is in a much stronger position than one approving a vague request.

The Point

AI does not need root to create value.

It can create enormous value by improving the quality of engineering review before production is touched.
